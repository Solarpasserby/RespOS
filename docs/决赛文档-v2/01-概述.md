## 1.1 项目介绍

RespOS 是一个使用 Rust 编写的宏内核操作系统，支持 RISC-V64 和 LoongArch64 双架构，面向全国大学生操作系统比赛的赛道要求。内核以 Linux 用户态兼容为主要目标，提供接近 Linux ABI 的系统调用接口，并通过比赛镜像中的 musl/glibc 程序持续验证语义正确性。

在内核设计上，RespOS 遵循几条贯穿始终的原则。公共逻辑跨架构复用，RISC-V64 与 LoongArch64 的差异收敛到 HAL、启动、trap 处理和页表等架构相关层。系统调用层保持"薄"，负责解析 ABI 和校验参数，真正的状态机由各领域模块维护。资源生命周期通过 Rust 的所有权和 RAII 机制管理，失败路径保持原子性——新资源准备成功后才替换旧状态。

## 1.2 整体架构

RespOS 可以分为四个层次：

**机器层（Machine Layer）**。内核需要运行于 RISC-V64 和 LoongArch64 架构，同时支持 QEMU 虚拟机与物理开发板。这些平台和架构的差异被封装在机器层中，由上层硬件抽象层统一。

**硬件抽象层（HAL）**。HAL 将底层硬件差异统一为 trait 接口，向上层内核提供统一的页表操作、trap 处理、上下文切换、中断控制等能力。内核子系统通过调用 HAL 接口实现与底层硬件的完全解耦。

**内核实现层**。这是内核的核心，包含进程管理、内存管理、文件系统、信号系统、时钟管理、网络模块等子模块。每个模块通过统一的系统调用接口向用户态提供服务。

**用户应用层**。基于内核提供的系统调用接口运行用户程序。内核内嵌初始进程用于启动用户态执行链，赛事测例运行于这一层。

项目源码结构：

```
RespOS
├── os/src/
│   ├── arch/           # RV64 与 LA64 架构相关代码（entry, trap, context, timer）
│   ├── drivers/        # 设备驱动（virtio 块设备/网卡）
│   ├── fs/             # 文件系统（VFS, ext4, procfs, devfs, pipe, page_cache）
│   ├── mm/             # 内存管理（frame_allocator, heap_allocator, memory_set）
│   ├── net/            # 网络模块（TCP, UDP, socket, loopback）
│   ├── signal/         # 信号子系统
│   ├── syscall/        # 系统调用分发
│   ├── task/           # 进程与调度（task, scheduler, processor, context, futex）
│   └── main.rs         # 内核入口
├── user/               # 用户态运行时与测例
└── vendor/             # 第三方依赖
```

## 1.3 模块完成情况

| 模块 | 完成情况 |
|------|---------|
| HAL 模块 | 实现自有 HAL 抽象，支持 RISC-V64 和 LoongArch64 双架构启动、陷入处理、上下文切换与页表操作 |
| 进程管理 | 统一进程/线程数据结构（TCB），同步有栈上下文切换，多核 SMP 支持（RV64），细粒度字段分类加锁，vfork 同步语义，exec sibling quiescence 协议 |
| 内存管理 | 物理页帧分配、内核堆管理、完整虚拟地址空间模型（MemorySet→VMA→PTE），支持 COW、lazy allocation、file-backed ELF、mmap 文件映射与共享写回，FDT 动态物理内存识别 |
| 文件系统 | 类 Linux VFS 架构（SuperBlock→Inode→Dentry→File），支持 ext4、procfs、devfs、tmpfs/shm，页缓存加速读写，全路径存储 dentry 缓存，挂载子系统与跨文件系统路径穿越，孤儿文件语义 |
| 信号系统 | 标准信号与实时信号，线程私有 pending/mask + 进程共享 handler，sigframe 构造与 sigreturn，alt stack、SA_SIGINFO |
| 时钟模块 | 时间轮和最小堆混合结构的定时器管理，支持 nanosleep、interval timer、POSIX timer、timerfd |
| 网络模块 | 基于 smoltcp 协议栈，TCP/UDP socket、loopback、virtio-net、IPv4/IPv6 |
| IPC 系统 | 管道（阻塞/非阻塞、poll/epoll、EOF 生命周期）、futex（含 CMP_REQUEUE、wake/timeout/signal 竞态处理）、System V 共享内存 |
| 设备驱动 | virtio 块设备/网卡驱动、串口驱动、中断控制器驱动 |
