# 决赛文档当前排版基线

> 当前版本仅作为内容继续修改期间的排版基线，不是最终视觉规范。内容、术语和图片稳定后仍需进行一次终版排版检查。

## 构建入口

- Markdown 源文件位于 `docs/决赛文档/markdown/`。
- 使用 `bash docs/决赛文档/build.sh` 生成 `chapters/*.typ` 和 `决赛文档.pdf`。
- 不直接编辑自动生成的 `chapters/*.typ`。

## 当前样式

- A4 页面，保留封面和独立目录；Typst `outline` 提供 PDF 目录跳转。
- 封面不显示页号，目录从 1 开始编号，正文延续页号。
- 正文为 12pt，两端对齐，两字符首行缩进，行距为 `1.05em`。
- 一级章节标题换页、居中；二级标题使用黑体 16pt，三级标题使用黑体 13.5pt，标题上下保留明显间距。
- 中文正文使用衬线字体；英文暂时沿用普通正文样式，不自动加粗，也不自动判断术语和代码。
- 行内反引号内容暂时使用正文同字号，避免英文、数字和代码标识出现视觉大小差异。代码块使用 9.5pt 等宽字体和浅灰背景。
- 图片、图题、表题和代码片段题注居中。

## 后续终版处理

待正文内容稳定后，再统一检查英文术语、内核代码反引号、表格密度、图片尺寸、题注编号和最终分页。
